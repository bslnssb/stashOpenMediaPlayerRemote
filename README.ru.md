# Stash Open Media Player Remote

**Один щелчок — и сцена Stash открывается в вашем плеере: VLC, MPV, MPC-HC, SMPlayer, PotPlayer. Плеер получает исходный файл, а не транслируемый браузером поток, и всё это работает, даже если Stash запущен в Docker на NAS.**

## Что делает плагин

На каждой странице сцены в панели инструментов появляется кнопка **Открыть во внешнем плеере**. Один щелчок передаёт реальный путь файла этой сцены вашему плееру на компьютере.

- **Один щелчок, кнопка всегда на месте** — она стоит рядом со счётчиком просмотров и не требует открывать вкладку «Файлы».
- **Любой плеер** — подойдёт всё, что запускается как «exe + путь к файлу»: VLC, MPV, MPC-HC/BE, SMPlayer, PotPlayer и т. д. Нужно только указать полный путь к исполняемому файлу.
- **Локальный режим** — Stash и плеер на одном компьютере: плеер запускает сам сервер Stash.
- **Удалённый режим** — Stash в Docker / Unraid / на NAS / на другом компьютере: браузер передаёт ссылку `stashopenmediaplayerremote://` небольшому помощнику на вашем ПК, и тот запускает плеер локально. Серверу не нужен доступ к вашему рабочему столу.
- **Сопоставление путей** — замена путей контейнера на реальные, например `/data` → `//NAS/stash`.
- **Формат пути под плеер** — `file://`-URL или обычный путь: определяется автоматически (VLC и MPC ведут себя по-разному) либо задаётся принудительно через `keep` / `remove`.
- **Счётчик просмотров (необязательно)** — открытие во внешнем плеере тоже считается просмотром.

### Зачем вообще внешний плеер

Встроенный плеер Stash либо перекодирует видео, либо полагается на кодеки браузера: высокая нагрузка на процессор, слабая поддержка ASS-субтитров и HDR. Настольный плеер открывает исходный файл с аппаратным декодированием, переключением субтитров и аудиодорожек, HDR и горячими клавишами — и снимает нагрузку с сервера.

## Установка

1. В **Настройки → Плагины → Доступные → Добавить источник** добавьте источник:

```text
Имя:
stashOpenMediaPlayerRemote

URL:
https://raw.githubusercontent.com/bslnssb/stashOpenMediaPlayerRemote/refs/heads/main/index.yml
```

![Добавление источника](images/add-source.jpg)

2. Установите **Stash Open Media Player Remote** из этого источника.

![Установка плагина](images/install-plugin.jpg)

3. В настройках плагина укажите **Media Player Path** — полный путь к плееру, например `C:\Program Files\SMPlayer\smplayer.exe`.
4. Только для удалённого режима: включите **Use Remote Protocol Handler** и один раз запустите помощник на компьютере с плеером (см. ниже).
5. Перезагрузите Stash в браузере сочетанием <kbd>Ctrl</kbd>+<kbd>F5</kbd>.

## Настройки

| Параметр | Что делает |
|---|---|
| **Media Player Path** | Полный путь к exe плеера, например `C:\Program Files\SMPlayer\smplayer.exe` |
| **File URL Prefix Mode** | `auto` (по умолчанию: VLC получает `file://`, MPC — обычный путь), `keep` (всегда `file://`), `remove` (всегда обычный путь) |
| **Use Remote Protocol Handler** | Включите для Docker / Unraid / NAS / удалённого Stash: запускается помощник на ПК, а не на сервере |
| **Path Mapping From / To** | Необязательная замена префикса, например `/data` → `//NAS/stash` |
| **Increment Play Count** | Увеличивать счётчик просмотров при внешнем открытии |

![Настройки плагина](images/plugin-config.jpg)

## Удалённый режим (Docker, Unraid, NAS)

Браузер открывает `stashopenmediaplayerremote://open?player=...&path=...`, и плеер запускается на вашей машине. Помощник ставится один раз на каждый компьютер, где нужно воспроизведение:

```bash
python install-stashOpenMediaPlayerRemote.py
```

Скрипт регистрирует протокол в реестре Windows либо как обработчик `.desktop` в Linux через `xdg-mime`. На Windows права администратора не нужны.

![Установка обработчика протокола](images/install-protocol.jpg)

При первом нажатии кнопки разрешите открытие в диалоге браузера.

## Решение проблем

### Файл не найден

- **Path Mapping From** совпадает с путём, который хранит Stash (он виден на странице сцены).
- **Path Mapping To** указывает на ресурс, реально доступный с этого компьютера.
- Путь после замены открывается из проводника.

Пример: `/data` → `//network_path/stash`

### Кнопка не появляется

Перезагрузите Stash после установки или обновления плагина. Если не помогло — **Настройки → Плагины** и перезагрузите плагины. После обновления нужно обновить и страницу, и список плагинов.

### Отключить запрос протокола в браузере (необязательно)

Браузеры на Chromium спрашивают подтверждение при каждом открытии `stashopenmediaplayerremote://`. Разрешить навсегда можно политикой `AutoLaunchProtocolsFromOrigins` (JSON — в английском README, раздел Troubleshooting). Ключ политики: Chrome — `HKEY_CURRENT_USER\Software\Policies\Google\Chrome`, Edge — `HKEY_CURRENT_USER\Software\Policies\Microsoft\Edge`. Портативные сборки могут игнорировать системные политики; шаг полностью необязательный.

## Что изменено в этом форке (относительно upstream v1.0.2)

Этот репозиторий — **неофициальный форк**. Сам плагин создан [MrArgparse](https://github.com/MrArgparse/stashOpenMediaPlayerRemote); здесь он приведён в рабочее состояние на Windows с путями, содержащими не-ASCII символы, и сделан пригодным для надёжной установки.

- **Падение на путях с не-ASCII символами (главное исправление)** — Stash отправляет корректный UTF-8 JSON, но Python в Windows декодировал его системной ANSI-кодовой страницей (cp936 / cp932 / cp949 / cp1251 …): символы искажались, один из двух обратных слэшей `\\` «съедался», `json.loads` выбрасывал `Invalid \escape`, задача завершалась с кодом 1, и плеер не запускался. Теперь stdin читается как сырые байты и декодируется в UTF-8.
- **Щелчок без реакции** — путь берётся тем же GraphQL-запросом `findScene(id){files{path}}`, DOM/XPath остаётся только запасным вариантом; ошибка запроса настроек больше не убивает обработчик молча.
- **Пропадающая кнопка** — вставляется в `.scene-toolbar` и поддерживается `MutationObserver`, поэтому переживает переходы SPA и перерисовку панели.
- **Видимые ошибки** — любая неудача показывает причину во всплывающем уведомлении.
- **Нет утечки учётных данных** — в журнал больше не пишется `server_connection` с cookie сессии и ApiKey.
- **Гигиена поставки** — воспроизводимый zip, привязка `index.yml` к хешу пакета, самопроверка целостности, документация на 13 языках.

Патчи, готовые для upstream (без изменений только для CJK), лежат в [patches/](patches/); лицензия и авторство — в [NOTICE.md](NOTICE.md). Если upstream выпустит исправление, вернитесь на его источник.

## Совместимость

- Проверено на **Windows 11 + Stash v0.31.1** (Chrome / Edge). Плагин использует стандартный `PluginApi` и задачу `raw`, поэтому свежие версии Stash должны работать.
- Помощник протокола ставится в **Windows** (реестр) и **Linux** (`xdg-mime`). На macOS работает локальный режим, но помощник пока не устанавливается скриптом.
- Для Docker / Unraid / NAS нужен **удалённый режим** и сопоставление путей.
