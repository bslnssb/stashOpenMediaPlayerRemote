## 简体中文 (`cp936 / gbk`)

**问题 / Problem:** 在 Windows 上，如果 Stash 安装目录或视频路径含中文等非 ASCII 字符，点击「外部播放器」完全没反应；Stash 日志里是 `Invalid \escape` / `exit status 1`。

**原因 / Cause:** 插件后端用 `sys.stdin.read()` 读 Stash 写出的 UTF-8 JSON，Windows 会按系统 ANSI 代码页 cp936 解码，中文变乱码并吞掉一个转义反斜杠。

**修法 / Fix:** 改成 `sys.stdin.buffer.read().decode('utf-8')` 直接读原始字节。非官方修复版见 fork 链接。

**安装 / Install:** 在 Stash「设置 → 插件 → 源」添加 `index.yml` 地址，或手动替换 `src/` 里的 `.py` / `.js`；改完浏览器按 Ctrl+F5 强刷。

## 繁體中文 (`cp950`)

**问题 / Problem:** 在 Windows 上，若 Stash 安裝目錄或影片路徑含中文等非 ASCII 字元，按下「外部播放器」完全沒有反應；Stash 記錄會出現 `Invalid \escape` / `exit status 1`。

**原因 / Cause:** 外掛後端以 `sys.stdin.read()` 讀取 Stash 輸出的 UTF-8 JSON，Windows 會用系統 ANSI 字碼頁 cp950 解碼，中文字變亂碼並吃掉一個跳脫反斜線。

**修法 / Fix:** 改用 `sys.stdin.buffer.read().decode('utf-8')` 直接讀原始位元組。非官方修正版見 fork 連結。

**安装 / Install:** 在 Stash「設定 → 外掛 → 來源」加入 `index.yml` 網址，或手動替換 `src/` 的 `.py` / `.js`；改完瀏覽器按 Ctrl+F5 強制重新整理。

## 日本語 (`cp932`)

**问题 / Problem:** Windows で Stash のインストール先や動画のパスに日本語などの非 ASCII 文字が含まれると、「外部プレイヤー」ボタンを押しても何も起きません。Stash のログには `Invalid \escape` / `exit status 1` が出ます。

**原因 / Cause:** プラグインのバックエンドが `sys.stdin.read()` で Stash の UTF-8 JSON を読むため、Windows がシステムの ANSI コードページ (cp932) でデコードし、文字化けとエスケープ破壊が起きます。

**修法 / Fix:** `sys.stdin.buffer.read().decode('utf-8')` で生バイトを読むようにします。修正版は fork を参照してください。

**安装 / Install:** Stash の「設定 → プラグイン → ソース」に `index.yml` の URL を追加するか、`src/` の `.py` / `.js` を差し替えてください。変更後はブラウザで Ctrl+F5 です。

## 한국어 (`cp949`)

**问题 / Problem:** Windows에서 Stash 설치 경로나 동영상 경로에 한글 등 비 ASCII 문자가 있으면 '외부 플레이어' 버튼이 아무 반응도 하지 않습니다. Stash 로그에는 `Invalid \escape` / `exit status 1` 이 남습니다.

**原因 / Cause:** 플러그인 백엔드가 `sys.stdin.read()` 로 UTF-8 JSON을 읽어 Windows 시스템 ANSI 코드페이지(cp949)로 디코딩하면서 문자가 깨지고 이스케이프가 손상됩니다.

**修法 / Fix:** 원시 바이트를 `sys.stdin.buffer.read().decode('utf-8')` 로 읽으면 해결됩니다. 수정본은 포크를 참조하세요.

**安装 / Install:** Stash '설정 → 플러그인 → 소스'에 `index.yml` 주소를 추가하거나 `src/` 의 `.py` / `.js` 를 교체하세요. 이후 브라우저에서 Ctrl+F5.

## Русский (`cp1251`)

**问题 / Problem:** В Windows, если путь установки Stash или путь к видео содержит не-ASCII символы (кириллицу и т. п.), кнопка внешнего плеера никак не реагирует; в журнале Stash — `Invalid \escape` / `exit status 1`.

**原因 / Cause:** Бэкенд читает UTF-8 JSON через `sys.stdin.read()`, и Windows декодирует его системной ANSI-кодовой страницей (cp1251), искажая символы и escape-последовательности.

**修法 / Fix:** Читать сырые байты: `sys.stdin.buffer.read().decode('utf-8')`. Исправленная версия — в форке.

**安装 / Install:** Добавьте URL `index.yml` в «Настройки → Плагины → Источники» Stash или замените `.py` / `.js` из `src/`; затем Ctrl+F5 в браузере.

## Deutsch (`cp1252`)

**问题 / Problem:** Unter Windows reagiert die Schaltfläche für den externen Player nicht, wenn der Installationspfad von Stash oder der Videopfad Nicht-ASCII-Zeichen (z. B. Umlaute) enthält; im Stash-Log steht `Invalid \escape` / `exit status 1`.

**原因 / Cause:** Das Backend liest das UTF-8-JSON mit `sys.stdin.read()`; Windows dekodiert dabei mit der ANSI-Codepage (cp1252), wodurch Zeichen und Escape-Sequenzen beschädigt werden.

**修法 / Fix:** Rohbytes direkt lesen: `sys.stdin.buffer.read().decode('utf-8')`. Korrigierte Version im Fork.

**安装 / Install:** URL der `index.yml` unter „Einstellungen → Plugins → Quellen“ hinzufügen oder `.py` / `.js` aus `src/` ersetzen; danach im Browser Ctrl+F5.

## Español (`cp1252`)

**问题 / Problem:** En Windows, si la ruta de instalación de Stash o la del vídeo contiene caracteres no ASCII (ñ, tildes…), el botón del reproductor externo no responde; el registro muestra `Invalid \escape` / `exit status 1`.

**原因 / Cause:** El backend lee el JSON UTF-8 con `sys.stdin.read()` y Windows lo decodifica con la página de códigos ANSI (cp1252), dañando caracteres y secuencias de escape.

**修法 / Fix:** Leer los bytes tal cual: `sys.stdin.buffer.read().decode('utf-8')`. Versión corregida en el fork.

**安装 / Install:** Añade la URL del `index.yml` en «Ajustes → Plugins → Fuentes» de Stash o sustituye `.py` / `.js` desde `src/`; después Ctrl+F5 en el navegador.

**修法 / Fix:** Διαβάστε τα ακατέργαστα bytes: `sys.stdin.buffer.read().decode('utf-8')`. Η διορθωμένη έκδοση βρίσκεται στο fork.

**安装 / Install:** Προσθέστε το URL του `index.yml` στις «Ρυθμίσεις → Πρόσθετα → Πηγές» του Stash ή αντικαταστήστε τα `.py` / `.js` από το `src/`· μετά Ctrl+F5 στον browser.
